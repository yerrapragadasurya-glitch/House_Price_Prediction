# 🏠 House Price Prediction using Machine Learning

## 📊 Project Overview

This project is a **Machine Learning-based House Price Prediction system** that predicts the sale price of a house based on important property features.

The project covers the complete Machine Learning workflow:

- Data loading
- Data cleaning
- Exploratory Data Analysis
- Feature selection
- Model training
- Model evaluation
- Model saving using Joblib
- FastAPI deployment
- HTML, CSS and JavaScript frontend
- Real-time house price prediction

## 📁 Dataset

The dataset contains information about houses and their selling prices.

### Dataset Columns

| Column | Description |
|---|---|
| `Id` | Unique ID of the house |
| `OverallQual` | Overall quality of the house |
| `GrLivArea` | Above-ground living area |
| `GarageCars` | Garage capacity in number of cars |
| `TotalBsmtSF` | Total basement area |
| `YearBuilt` | Year the house was built |
| `FullBath` | Number of full bathrooms |
| `BedroomAbvGr` | Number of bedrooms above ground |
| `LotArea` | Total lot area |
| `SalePrice` | Selling price of the house |
